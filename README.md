# MOKA — Minimalist Artisanal Furniture

Moka is a premium e-commerce experience built with **Next.js 15**, focused on high-end furniture and artisanal craftsmanship. The platform features a seamless shopping journey, from editorial storytelling to a functional Zustand-powered cart.

## ✨ Key Features

* **Dynamic Product Routing**: Individual detail pages for every piece in the collection.
* **Zustand Cart System**: Persistent shopping bag with increment/decrement logic and local storage sync.
* **Editorial Design**: A "Slow Design" aesthetic using a custom `#F5EBE0` cream and `#2D2424` wood-tone palette.
* **Framer Motion Animations**: Smooth staggered reveals and page transitions.
* **Responsive Layout**: Fully optimized for desktop, tablet, and mobile viewing.

## 🛠️ Tech Stack

* **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **State Management**: [Zustand](https://github.com/pmndrs/zustand)
* **Animations**: [Framer Motion](https://www.framer.com/motion/)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Notifications**: [React Hot Toast](https://react-hot-toast.com/)
